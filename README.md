# AI 教育 SSCI 研究回顧網站

這是「人工智慧應用於教育的 SSCI 研究回顧」靜態網站。網站依序呈現 12 張投影片，每張投影片後附繁體中文與英文口語講稿。

## 網站內容

- `index.html`：投影片與雙語講稿
- `styles.css`：網站樣式
- `script.js`：語言切換與投影片導覽
- `assets/slides/`：投影片圖片

網站使用純 HTML、CSS 與 JavaScript，無需套件安裝或建置步驟。

## 本機預覽

在此資料夾執行：

```sh
python3 -m http.server 8000
```

再開啟 `http://localhost:8000`。

## 研究範圍

回顧資料來自 Web of Science Core Collection 的 SSCI 教育研究，涵蓋 2021 至 2025 年。檢索結果共 2,356 筆。本網站人工核閱 9 篇代表文獻摘要，這不代表已逐篇審查所有檢索紀錄。
